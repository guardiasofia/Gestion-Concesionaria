# 🚗 Sistema de Gestión de Concesionaria

**Trabajo Integrador para Programación I**  
Tecnicatura Universitaria en Desarrollo Web

## 📝 Descripción

Este proyecto consiste en un sistema de gestión para una **concesionaria de vehículos**, desarrollado en **Python**, con una **interfaz gráfica** para facilitar la administración de datos.

Permite **agregar, modificar y eliminar** información relacionada con:

- Vehículos 🚘  
- Clientes 👤  
- Transacciones 💰

## 🛠️ Tecnologías Utilizadas

- Lenguaje: Python 
- Almacenamiento: Archivos `.json`
- Interfaz Gráfica: Tkinter

## 📁 Estructura del Proyecto

.
├── cargar_guardar_datos.py   # Funciones para manejo de archivos JSON  
├── clientes.json             # Base de datos de clientes  
├── transacciones.json        # Base de datos de transacciones  
├── vehiculos.json            # Base de datos de vehículos  
├── sistema_gestion.py        # Lógica principal del sistema  
└── README.md                 # Documentación del proyecto  

## 🧪 Funcionalidades

- Registrar y actualizar vehículos  
- Gestión de clientes  
- Registro y visualización de transacciones  
- Persistencia de datos mediante archivos JSON

## ▶️ Cómo ejecutar el proyecto

1. Clonar el repositorio:
   git clone https://github.com/tu_usuario/tu_repositorio.git
   cd tu_repositorio

2. Ejecutar el archivo principal:
   python sistema_gestion.py

> Asegurate de tener Python instalado en tu equipo.
